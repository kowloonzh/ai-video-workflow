# 第 2 步：分镜——镜头语言、构图、配色

这是前期最重要的一步。故事再好，镜头没设计好，画面就会很平。构图和配色甚至比剧情更决定成片质量。

## 有参考片就先学参考片

用户有参考片时，先用 ffmpeg 抽帧（`scripts/extract_frames.sh`），逐帧看，把这些都量出来写成笔记，再模仿：

- 每个镜头的时长、景别、机位高度和角度
- 运镜方式和速度
- 人物进出画的方向和时机，人在画面里占多大比例、在什么位置
- 切镜方式（硬切、遮挡转场、动作接动作）
- 主色和强调色

没有参考片，就按下面的规则自己构思。

## 分镜规则

1. **每镜换角度**。全片平视正面最多两次，其余用俯拍、仰拍、从背后、过肩、透过东西拍（门缝、树叶、玻璃、人群缝隙）。机位越多，画面越丰富。
2. **画面里要一直有东西在动**，否则观众看到的就是一张图，画面就死了。
   - 大多数镜头里，要有人或东西从画面外进来，或者从画面里出去。所以每镜要设计清楚人怎么走。
   - 人不走动的镜头（比如一直坐着），就让别的东西动：飘过的一张纸、身后走过的路人、晃动的树影。
   - 固定机位最容易呆板，更要让人在画面里走动，比如从远处走到近处。
3. **景别要轮换**。不要连着好几镜都是同样大小，全身、半身、脸部特写换着来。
4. **每镜写清楚"什么在动"**：摄影机、焦点（从一个人换到另一个人）、光线、镜头前飘过的东西、人物小动作（比如手在抖），至少有一样。一样都写不出来，说明这镜还没想好。但也不要全片一直晃，该动的地方动，该静的地方静，才有对比。
5. **镜头运动要有理由**。摄影机一动，一定是有东西想给观众看。最常用的三种：
   - 跟着一个人或物走（信飞到哪，镜头跟到哪）
   - 慢慢推近，给特写
   - 一开始拍得很近，慢慢拉远，交代环境
6. **每一秒截图都要好看**。人的头或眼睛放在画面从左往右约 38% 或 62% 的位置（接近黄金分割），不要放正中间。

## 配色单独设计

配色不要交给模型自由发挥，要在画第一张图之前定好。

- 先问用户的偏好；没想好就给 2–3 个方案（每个方案写主色、辅色、强调色和情绪），并给出推荐。
- 把每一场用什么颜色列成一张**色表**（存成 `02-storyboard/palette.md`，色值写 HEX）：场次 / 主色 / 辅色 / 强调色 / 光线方向和冷暖 / 肤色基准。
- 强调色要少用，留给最重要的东西（主角的衣服、关键道具）。

## 分镜表格式（`02-storyboard/storyboard-vN.md`）

每镜一行（或一个小节），字段：

| 字段 | 说明 |
|---|---|
| 镜号 | 01, 02 … |
| 片中时间 | 起止秒数；配歌时按小节算 |
| 生成秒数 | 片中时长向上取整，尽量多留 0.5 秒；模型时长档位固定的按档位取整 |
| 景别 | 远景 / 全景 / 中景 / 近景 / 特写 |
| 机位 | 高度 + 角度，例如"低机位仰拍，从主角右后方" |
| 运镜 | 推 / 拉 / 摇 / 移 / 跟 / 固定，以及速度 |
| 调度 | 谁往哪走，用**画面的左右**来写（不要用角色自己的左右） |
| 表情推进 | 这一镜靠什么表情变化推进 |
| 什么在动 | 至少一样 |
| 构图 | 主体在 38% 还是 62%，前景 / 背景有什么 |
| 转下一镜 | 怎么切过去 |
| 风险 | 命中了哪条 AI 弱点 |

## 色块草图 + 黑白检查

用 Python（Pillow）给每个镜头画一张 1920×1080 的色块草图（按用户的画幅调整）：

- 用色表里的颜色填出大块的背景、主体、前景；
- 画出 38% 和 62% 两条竖线，标注主要的人和东西；
- 写上镜号和景别。

拼成一张总表（比如每行 4 张）给用户确认。然后**再转一版黑白**，自己看一遍：转成黑白后人和背景分不开，说明明暗对比不够，要回去调配色。

```

如果有参考片，先逐帧看参考片，把机位、进出画比例这些都量出来，然后学习模仿。没有参考片就按下面的要求自己构思。
```

## 关卡

分镜表、色表、色块总表都交给用户确认。分镜复杂时，可以开一个独立 agent，只给它故事和分镜表，让它按上面 6 条规则逐镜挑错（只挑错，不改文件）。
