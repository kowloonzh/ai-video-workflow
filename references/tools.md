# 工具接入

这个工作流和具体工具无关：一个生图工具（能参考图、能局部改图最好），一个图生视频模型（最好支持首尾帧），再加 ffmpeg 和 Python。开工时先确认用户用的是什么，再按下面对应的小节接入。没列到的工具，按"通用要求"自己查文档接入，写成脚本放进项目的 `07-post/` 或 `tools/` 目录里。

## 通用要求

- **生图**：每次只生成一张图；能传参考图（设定图、上一张首尾帧）；能做局部修改更好。
- **视频**：优先用**首尾帧**模式（first frame + last frame）。只支持首帧的模型，尾帧就作为"目标状态"写进提示词，抽卡率会高一些，要提前告诉用户。
- **API key** 放环境变量里，脚本从环境变量读，绝不打印、不写进文件、不写进日志。
- **生成任务通常是异步的**：先提交任务，再轮询状态，最后下载结果。下载后立刻存进 `06-clips/shotNN/`，文件名里带上版本号和模型名。
- **记账**：每次提交前先算出预估费用，提交后把任务 id、秒数、分辨率、预估费用记到 `review-log.md`。实际价格以平台账单为准。
- **欠费或额度用尽**就停，不要重试刷接口。

## Codex 生图（文章作者和本 skill 用户都在用）

调用方式（只读沙箱，跳过 git 检查，提示词从 stdin 读入）：

```bash
codex exec --skip-git-repo-check -s read-only -i 参考图.png - < 提示词.txt
```

- 有多张参考图就传多个 `-i`。没有参考图就去掉 `-i`。
- 提示词开头固定写：`Use your image generation tool to create exactly ONE image. Do not run shell commands.`
- 生成的图在 `~/.codex/generated_images/<session id>/`，session id 在 codex 的输出日志里。拿到后**复制**到项目目录对应位置，按版本重命名。
- 如果当前导演本身就是 Codex，就直接用它自己的生图工具。

注意事项：
- Codex 就算只改一小块，也会把整张图重新处理一遍，其他区域会悄悄变化。只改局部时，用 Python 把改好的那一块贴回原图（必要时羽化边缘）。
- 出图不一定正好是目标画幅（比如 16:9），交给视频模型之前要检查并裁好；同一镜的首帧和尾帧尺寸必须完全一样。`scripts/check_keyframes.py` 可以检查这两点。
- 额度有限（OpenAI 合并额度后更明显）：不要一次并发画太多张；额度用完就等它恢复，不要买额度。先过审"首尾帧计划"再画，能省很多额度。

## Seedance（火山方舟）——文章作者的视频模型，供参考

- 接口：`POST https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks`（提交任务，之后用任务 id 查询状态）。具体请求格式查火山方舟文档。
- Key：环境变量 `ARK_API_KEY`。
- 模型与价格（文章写作时，以账单为准）：
  - `doubao-seedance-2-5-260628`：720p 约 ¥1.5/秒，能力更强。
  - `doubao-seedance-2-0-mini-260615`：720p 约 ¥0.5/秒。不太复杂的镜头用它就够了。
- 已知怪癖见 `model-quirks.md`。

## 其他视频模型（可灵、即梦、Runway、Veo 等）

先确认用户用 API 还是网页版：

- **API**：查官方文档，写一个提交 + 轮询 + 下载的脚本。首尾帧参数、时长档位（很多模型只支持 5 秒 / 10 秒这样的固定档位）、分辨率和单价都记进 `00-brief.md`。
- **网页版 / 手动操作**：你负责产出"提交包"，即首帧、尾帧、提示词（按平台字数限制压缩过的版本）、时长和参数，放在 `05-prompts/shotNN/submit/` 里交给用户手动提交。用户把下载的视频放进 `06-clips/shotNN/` 后，你接着检查。

时长档位固定的模型：分镜里"生成秒数"按档位向上取整，多出来的部分后期剪掉或变速。

## ffmpeg / Python

- 后期全部写成脚本（放 `07-post/`），方便改一个参数就重跑。
- 常用的检查工具在本 skill 的 `scripts/` 下：
  - `scripts/check_keyframes.py 首帧 尾帧 [--aspect 16:9]`：检查尺寸是否一致、画幅是否正确，并输出叠加对比图和差异热图，方便看不该变的地方有没有变。
  - `scripts/extract_frames.sh 视频 输出目录 [每秒帧数]`：抽帧检查（默认每秒 4 帧），同时导出首帧、尾帧和帧信息。
