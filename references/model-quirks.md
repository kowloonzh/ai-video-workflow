# 模型怪癖库

记录各个模型稳定可复现的毛病和对策。写提示词、做提交前审核、做后期时都要查一下当前用的模型。每次做完片子，如果发现了新的问题，经用户同意后追加到这里（写清模型版本和日期）。

## Seedance 2.5（doubao-seedance-2-5-260628）——来源：Eian 的文章

| 问题 | 对策 |
|---|---|
| 写了"没有音乐"还是混进了音乐 | 片段自带的声音不用，后期另外配 |
| 结尾几帧突然跳到尾帧的样子 | 后期选一张没问题的画面，之后都定格在这一张 |
| 第一帧特别锐 | 直接剪掉第一帧 |
| Seedance 输出的 mp4 色彩 | 按 BT.601 解码（见 `post.md`） |

## Seedance 2.0 mini（doubao-seedance-2-0-mini-260615）——来源：Eian 的文章

| 问题 | 对策 |
|---|---|
| 视频越到后面越暗、越冷 | 每条视频都按它自己的首帧把颜色调回来 |
| （优点）自带音效经常能直接用 | 请用户听过再决定 |

## Codex 生图——来源：Eian 的文章

| 问题 | 对策 |
|---|---|
| 只改一小块也会把整张图重新处理 | 改好的那一块贴回原图 |
| 出图不一定正好是目标画幅 | 提交视频前检查并裁切，首尾帧尺寸一致 |
| 额度消耗快 | 先过审计划再画；不要并发画太多；用完就等恢复 |
