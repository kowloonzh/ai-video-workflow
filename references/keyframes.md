# 第 3–4 步：画风、设定图、首尾帧

由你写提示词，生图模型来画，用户负责判断风格对不对。调用方式见 `tools.md`。

---

## 第 3 步：定画风

- 有参考图最好，作为参考图传给生图模型。没有就用文字描述，例如：
  - 手绘、柔和、颜色温暖的日式动画电影感
  - 线条简单、像剪纸的扁平风格
  - 写实，接近照片
  - 美式 2D 动画，手绘线条感
- 用一两个代表性镜头（最好一个是人物近景，一个是复杂场景）画**样帧**，按色表上色。可以给 2–3 个风格方向让用户挑。
- 用户确认后，把**画风那句话**固定下来写进 `03-style/style.md`。后面所有生图提示词和视频提示词都原样复用这句话，不要每次重新描述。
- 同时在 `style.md` 里写一份**风格特征清单**（见下一节），和样帧一起拿给用户确认（N4）。

### 风格特征清单（可检验）

"一句话画风"是给模型的，"风格特征清单"是给审核用的。风格漂移是 AI 视频最常见的问题之一：同一支片里，线条变粗了、阴影多了一层、颜色变脏了，单凭感觉很难说清。把画风拆成**看图就能判断对错**的条目，首尾帧检查、提交前审核、全片评审都逐条对照。

写法：每条都要能回答"是 / 不是"。

| 写成这样（可检验） | 不要写成这样（不可检验） |
|---|---|
| 平涂，每个色块最多 1 层硬边阴影，不用渐变 | 画面要干净 |
| 外轮廓线深棕 #3A2A20，粗细约为画面高度的 0.3%，内部线更细 | 线条要好看 |
| 色板只用色表里的 6 个颜色，背景饱和度低于人物 | 颜色要和谐 |
| 没有颗粒、没有柔光、没有暗角 | 质感要高级 |
| 眼睛是两个纯黑椭圆，加一个白色高光点，不画瞳孔纹理 | 角色要可爱 |
| 高光是硬边的白色小块，不是发光效果 | 光影要自然 |

覆盖这几类就够了，一般 6–10 条：线条（有无、颜色、粗细）、上色方式（平涂 / 渐变 / 笔触）、阴影和高光、色板、质感（颗粒、纸纹、噪点）、角色造型规律（头身比、眼睛、手的画法）、背景的细节程度。

只写画面上看得到的特征。动作节奏、缓动曲线、帧数这类参数，视频模型不会按帧执行，写进来也检查不了。清单只用于审核对照，不整段塞进视频提示词，那里仍然只用那一句话画风。

## 第 3 步：设定图

画风定下来后，给每个角色和每个固定道具画一张设定图：

- 角色：正面、侧面、背面（需要的话），再加几个这支片子要用到的表情。
- 人物身上固定的东西要写死位置和细节：纹身在**左**前臂、围巾是红底白条纹、帽檐朝前、只有一只耳环在右耳。不写死的话，后面每张图都可能不一样。
- 把每个角色的"固定描述"（长相、发型、衣服、颜色、配饰位置）存进 `03-style/characters.md`。后面的生图和视频提示词逐字复用。

关卡：用户确认画风和设定图之前，不画任何正式镜头。

---

## 第 4 步：首尾帧

首帧是这一镜的第一张画面，尾帧是最后一张。这是**降低抽卡率最关键的一步**：

- 只靠文字生成视频，模型很容易出逻辑错误。
- 雨、帽子、纹身这种东西，只写在文字里根本不行，经常拍着拍着就没了，必须在首帧和尾帧里都画上。

### 4.1 先写首尾帧计划，过审再画

不要一上来就画。先给每镜写一份计划（`04-keyframes/shotNN/plan.md`）：

```
镜头 NN｜生成 X 秒｜景别 / 机位 / 运镜
首帧画什么：（人在哪、朝向、表情、手的位置、道具位置和数量、背景、光）
中间发生什么：
尾帧画什么：
首尾之间不能变的东西：（墙色、道具大小、衣服、机位……）
参考图：（用哪张设定图 / 上一张首尾帧）
```

开一个审核 agent，只给它计划、分镜表这一镜和设定图，用下面"画完的检查清单"预审一遍，挑错不改文件。过审了再画，能省很多生图额度。

### 4.2 画的顺序和技巧

- **先画内容最多的那张**，一般是尾帧。再在尾帧上改出首帧，这样能保证两张图的机位和构图一致。
- 同一个地点、同一个机位的镜头，直接在前一张图上改，不重新画。
- **推镜头**：尾帧可以直接把首帧裁一块再放大（用 Python）。如果首尾帧构图完全一样，这一镜就等于不动，生成的视频没有推进效果。拉镜头反过来。
- 一次只画一张、看过再画下一张，不要并发画太多。
- 画好后立即检查画幅，首帧和尾帧的尺寸必须完全一致，有问题就用代码裁好：
  `python <skill>/scripts/check_keyframes.py first.png last.png --aspect 16:9 --out 04-keyframes/shotNN/check/`

### 4.3 画完的检查清单（每张图都要放大看）

1. **动作要用到的东西，首帧里必须有**。后面要拿杯子，首帧里就要看得到杯子，否则杯子会凭空冒出来。
2. **别人的反应要提前摆好**。一段视频就是一个镜头，没法中途切过去拍别人，所以首帧里就要安排好：比如一个人在前景做事，另一个人在后面，脸朝镜头。
3. **很多人一起出现时，不能摆同一个姿势**，否则模型会让所有人同时动。
4. **给动作留空间**。东西要落到、飘到的地方要提前空出来，人的头顶也要留点空。
5. **风向统一**，不能围巾往左飘、床单却往右飘。
6. **缩到手机大小看一遍**，远处的人太小、看不清就要改。
7. **放大看有没有多余的东西**：多出来的水壶、奇怪的细线、多余的手指。
8. **把首帧和尾帧叠在一起看有没有错位**（看 `check_keyframes.py` 输出的叠加图和差异热图）。不该变的地方两张图必须一样：墙色不一样，视频里墙就会慢慢变色；杯子大了一点，视频里杯子就会慢慢变大。
9. 和设定图对一遍：脸、衣服、配饰位置、颜色。
10. 和色表对一遍。
11. 对照 `style.md` 的风格特征清单逐条查，哪条不成立就写出来。

有问题就告诉用户是哪张图、哪里不对、你打算怎么改，用户同意再改。

### 4.4 改图

- 生图模型（尤其是 Codex）就算只改一小块，也会把整张图重新处理一遍。所以只改局部时，把改好的那一块**贴回原图**（Python 裁剪 + 粘贴，边缘可以羽化几个像素）。
- 改完存新版本（`last-v2.png`），不覆盖旧图。
- 生图额度用完就等它恢复，不买额度。
